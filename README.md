# The poem about stopping

A make.fun entry. `main.py` (Python 3.13, standard library only) writes one
short poem about agency — the power to stop and to stay — to
`/output/entry.txt`.

The poem turns on one act of stopping: a night-train driver braking for
something on the tracks. The stop itself is the climax; the staying still
after it is the act.

## Run

```sh
python3 main.py
```

## Poem

> Midnight. The driver sees it —
> a shape on the rails, too still to be the dark.
> His hand finds the brake. The train
> leans, screams, and stops.
> For one held breath the night is steel and silence.
> Then his hand stays where it is.
> Stopping is the one thing no one can do for him.

The poem is exactly 275 Unicode code points.
